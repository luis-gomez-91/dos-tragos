# Dos Tragos

Sitio web de **Dos Tragos** - Coctelería profesional y servicios de bartender en Ecuador.

## 🍸 Sobre el proyecto

Dos Tragos ofrece experiencias únicas en el mundo de la coctelería: servicios para eventos, cócteles to go y clases de mixología.

## 🚀 Tecnologías

- [Astro](https://astro.build) - Framework web
- [Tailwind CSS](https://tailwindcss.com) - Estilos
- [tailwindcss-animated](https://github.com/Mickoust/tailwindcss-animated) - Animaciones

## 📁 Estructura

```
/
├── public/          # Assets estáticos (imágenes, videos, fuentes)
├── src/
│   ├── components/  # Componentes Astro
│   ├── css/         # Estilos globales
│   ├── layouts/     # Layouts de página
│   └── pages/       # Rutas de la aplicación
└── package.json
```

## 🧞 Comandos

| Comando        | Acción                                    |
| :------------- | :---------------------------------------- |
| `npm install`  | Instala dependencias                      |
| `npm run dev`  | Inicia servidor de desarrollo (puerto 4321) |
| `npm run build`| Genera build de producción en `./dist/`   |
| `npm run preview` | Vista previa del build local            |

## 📄 Páginas

- **/** - Inicio con presentación, servicios, sobre nosotros, menú y galería
- **/services** - Servicios de coctelería
- **/menu** - Menú de cócteles
